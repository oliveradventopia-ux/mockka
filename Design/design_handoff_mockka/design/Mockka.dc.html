Q14 · Domain 2 · concept C-007Correct
Why this holds

Live operational state belongs to the system of record, not to the agent. An agent that carries state cannot distinguish "unchanged" from "unobserved", so after a failover it answers from the last position it happened to hold. Reading state at decision time makes the freshness of the answer a property of the read, not of the agent's lifetime.

Why the others fail
A

More warm replicas multiply the number of agents holding the same stale position. Availability was never the failing property here; freshness was.

pattern D19 · scales the wrong axis
C

Ageing memory out removes the stale value without supplying a current one, leaving the agent to reason from an absence it cannot detect.

pattern D10 · treats the symptom
D

Confidence is calibrated against the state the agent believes it holds, so a stale-but-certain position clears any threshold you set.

pattern D09 · defensible but inert
